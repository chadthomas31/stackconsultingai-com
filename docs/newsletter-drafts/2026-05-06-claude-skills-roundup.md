# 10 Claude Code skills worth installing this week

GitHub trending hit 35 open-source skills this cycle. We sat through all of them, installed the ones that survived a real workflow, and cut the list to 10 — sorted by "will I open this Monday morning."

A *skill* is a Claude Code plugin: a `SKILL.md` plus scripts that ship as one repo. You add it with `/plugin marketplace add <owner>/<repo>` then `/plugin install <name>@<marketplace>`. That's it — no API keys for most, no daemon, nothing to babysit.

---

## The agent gets new senses

**1. Claude Video (`/watch`) — bradautomates/claude-video.** Claude can read web pages and run scripts. Out of the box, it cannot watch a video. `/watch` fixes that. Paste a YouTube link or a local `.mp4`, ask a question, and the skill runs `yt-dlp` to download, `ffmpeg` to extract auto-scaled frames, pulls captions (or Whisper as fallback), and hands the frames + timestamped transcript to Claude. By the time it answers, it has *seen* the video and *heard* the audio. *(Self-referential note: this newsletter was generated by running `/watch` on the very video it summarizes.)*

**2. claudedesign-to-swiftui.** Hand it a Claude-generated HTML/Tailwind design — URL or tarball — and it renders the prototype in an iPhone-sized Chrome viewport, screenshots it, then translates DOM and Tailwind classes into native SwiftUI. Output is a single, self-contained `.swift` file that compiles in Xcode 26.3+. Closes the gap between a design artifact and a real iOS demo without a designer-to-engineer handoff.

## Skills that fix the model itself

**3. WRITING.md — Anbeeld/WRITING.md.** A ruleset that strips AI-assisted text of em dashes, "not X, but Y" patterns, recognizable cadence, and unsolicited hedging. The README reads like a debug log against LLM defaults: kill repeated cadence, kill list-bloat, kill non-grammatical sentence-length variation, revise the most generic sentences and replace them with something specific. Calibrates voice to the audience and reading level you specify.

**4. Linus Torvalds skills — leophev/linus-torvalds-skills.** A `CLAUDE.md` plus rule files that force Claude into the Torvalds doctrine: no polite acceptance of bad architecture, call out bogus abstractions directly, demand numbers before accepting performance claims, fix data structures instead of spraying conditionals. Drops the "Sure! Here's a refactor that..." energy the moment you load it.

**5. Aerodani Speak (Rocky / Signal modes).** A token-compression skill modelled on Rocky from *Project Hail Mary* — warm but blunt, zero filler, mathematical density. Two modes: **Rocky** keeps personality but strips robotic AI slop; **Signal** strips everything down to notation-style output for agent pipelines. Same idea as our `/caveman` setup, different lineage. Worth comparing.

## Skills that audit your other skills

**6. Skill Doctor.** A local-first inspector for the skill graph itself. It crawls every skill installed in your Claude config, flags definition conflicts (which skill wins when two register the same trigger), maps which skill *actually* fires for each trigger word, and surfaces "risky instructions that should not stay hidden." If you've installed more than five skills, you have collisions you can't see — Skill Doctor makes them visible.

**7. mizchi/skills (APM bundle).** Mischief shipped its full battle-tested suite as a single APM-compatible repo (`apm install -g mizchi/skills/<name>`). The standout is **empirical prompt tuning** — a skill that *evaluates and auto-tunes your other skills'* prompts against test cases, scoring them for accuracy. Also bundles language-specific guards (e.g. the Moonbit best-practices skill stops agents from hallucinating niche syntax).

## Skills that compound on production work

**8. God Mode — `/work`.** Installs a `/work` command that fans your codebase out to OpenAI Codex, Google Gemini, and OpenCode in parallel. Each model independently reviews and hunts bugs from a different lineage; the main Claude agent literally cannot merge until multi-model consensus is reached. We already do a version of this with Codex MCP + `scripts/ask-gemini.sh` — God Mode formalizes it as a hard gate. Worth the setup if you're shipping anything customer-facing.

**9. OG image skill.** When the agent publishes a blog post, this skill reads the title and metadata, writes an HTML/canvas script to render a branded high-resolution OG image, and saves it straight to `public/`. The kind of tedious-manual task that either gets skipped or eats 20 minutes — automated to zero.

**10. Founder Playbook.** Fourteen of the most-cited startup books — *The Mom Test*, *Building a StoryBrand*, *$100M Offers* — distilled into hardcoded decision trees, scoring rubrics, and templates. Drop a customer interview transcript in and it scores your questions against Mom Test criteria. A built-in conflict-resolution matrix maps contradictions between books and decides which framework applies to *your* situation. Pairs well with the AI readiness audits we run for clients.

## Honorable mentions

A few we didn't have room to feature, worth bookmarking:

- **Sprite-sheet pipeline** — `Generate a 4x4 walk cycle for a fire mage` → engine-ready transparent PNGs + animated GIFs + layered RPG maps for Godot/Unity.
- **Shots** — point it at an App Store URL or raw screenshots, get back stylized 1290×2796 marketing screens via GPT Image 2.
- **Third Brain V5** — architectural skills, cost-aware LLM pipeline routing, zero-downtime DB migration workflows, automated OWASP reviews. A whole second brain you assign to a dedicated terminal.
- **Compose Performance (Skydoves)** — Android-only; teaches the agent to diagnose stability issues, optimize lazy layouts, apply baseline profiles, and trace recompositions. Grounded in primary sources, no hallucinated APIs.
