> **NAP rule:** identical wording, identical formatting, identical phone format on every directory. Inconsistency drops local rankings faster than no listing at all. The strategy draft initially had `949-529-2424` — that was wrong. Canonical = `(949) 749-0001` (matches live footer + Yelp ad).

## Core principle

Backlinks should do one of three things:

1. Build trust for a new AI consulting brand.
2. Send local / business traffic.
3. Support service pages: AI receptionist, AI automation, AI consulting, web development.

If a link does none of those three, skip it.

## Semrush prospect triage rules

### Keep (worth outreach time)
- Blogs (real editorial)
- Directories with submission process
- Resource pages on relevant niches
- "Best AI tools" / "Best automation" lists
- Local business sites
- Partner/vendor pages on tools you use
- Guest-post-friendly sites
- AI tool directories with editorial review
- Small business education sites

### Skip (waste of time)
- Massive SaaS company pages (Intercom, Make, Zapier — won't link to a 1-person shop)
- Forums (unless you'd genuinely contribute, not link-drop)
- Random low-quality AI directories (PageRank zero, no traffic)
- Sites with no editorial control (link farms)
- Sites obviously selling spammy links
- Irrelevant foreign directories
- Direct competitors

## Anchor text policy (DO NOT use same anchor everywhere)

Google flags identical anchor backlink patterns as manipulation. Rotate:

| Anchor | Use % |
|--------|-------|
| "Web design by Stack Consulting AI" | 30% |
| "Built by Stack Consulting AI" | 20% |
| "AI consulting by stackconsultingai.com" | 15% |
| "Site by SCA" | 15% |
| `stackconsultingai.com` (raw URL) | 10% |
| Logo-only link (alt text only) | 10% |

## Deep link distribution

Don't send all backlinks to `/`. Mix:

- 60% → homepage (`/`)
- 25% → `/ai-receptionist`
- 10% → `/services`
- 5% → `/services/ai-consulting-orange-county`

Adjust per outreach target — health/medical site = link to `/ai-receptionist` (clinic angle); local OC site = OC service page.

## UTM tagging

```
?utm_source=<source>&utm_medium=backlink&utm_campaign=<campaign-slug>
```

Doesn't hurt SEO (canonical handles dedup). Lets you see referral traffic in GA4 + identify which placements actually drive humans.
